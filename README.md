# Forever Young — Premium Static Website

GitHub Pages / Vercel ready static site for Forever Young Skin & Hair Clinic, Selaqui, Dehradun.

## Included
- Premium responsive one-page design
- PRP, hair-care and skin sections with local images
- Clickable WhatsApp, Call and Instagram CTAs
- Patient review carousel ready for verified reviews
- FAQ accordion and mobile navigation
- SEO title/description + MedicalClinic structured data
- No build step required

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and the `assets` folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.

## Deploy on Vercel
1. Import the GitHub repository into Vercel.
2. Framework preset: **Other**.
3. No build command needed.
4. Output directory can stay blank/root.

## Before final client launch
Replace the three review placeholders in `index.html` with real, verified patient reviews approved by the clinic.
